Welcome to Tailmox

Prepare this host, one safe step at a time.

Tailmox protects cluster settings with one post-quantum age identity and gives every host its own dedicated Ed25519 signing key.

1

Create or import the age identity

Create the Tailmox identity on the first host, back it up, then import the same identity on every other host.

2

Encrypt and approve the configuration

Existing plaintext settings remain active until every registered host accepts the signed encrypted migration.

3

Stage the host

Install prerequisites, connect Tailscale, configure certificates, and start services without joining a Proxmox cluster.

4

Install analytics and monitor

Start the periodic analytics collector, then confirm cluster and network health before making cluster changes.
